# Manual de Uso – AgendaFácil

## 1. Acesso

1. Abra o endereço do sistema no navegador (computador ou celular).
2. Entre com e-mail e senha. Usuário de demonstração: **admin@agendafacil.com** / **admin123**.
3. Para dar acesso a outra pessoa da equipe, entre no sistema e clique em **+ Usuário** no menu. Informe nome, e-mail e uma senha de pelo menos 6 caracteres. Por segurança, não existe cadastro aberto na tela de login.

No celular, o menu fica no botão **☰** no canto superior direito.

## 2. Primeiros passos (ordem recomendada)

1. **Cadastre os serviços** do salão.
2. **Cadastre os clientes.**
3. **Faça os agendamentos.**

## 3. Serviços

Menu **Serviços → + Novo serviço**. Informe:

- **Nome** (ex.: Corte feminino) — não pode repetir;
- **Duração** em minutos (5 a 480) — é usada para calcular o fim do atendimento;
- **Preço** em reais (até R$ 999.999,99);
- **Serviço ativo** — desmarque para parar de oferecer sem perder o histórico.

**Excluir:** se o serviço já foi usado em algum agendamento, o sistema apenas o **desativa**.

## 4. Clientes

Menu **Clientes → + Novo cliente**. Informe nome, telefone com DDD (a máscara é automática) e, se quiser, e-mail.

- Use a **busca** para encontrar por nome ou telefone.
- Clientes que já têm agendamentos não podem ser excluídos.

## 5. Agendamentos

Menu **Agenda → + Novo agendamento** (ou o botão no Painel):

1. Escolha o **cliente** e o **serviço**.
2. Escolha **data e hora** de início.
3. Se quiser, escreva uma **observação** (ex.: "trazer foto da referência").
4. Clique em **Salvar**.

O sistema **não deixa** salvar quando:

| Situação | O que fazer |
|---|---|
| O horário já está ocupado | Escolha outro horário; a mensagem mostra com quem é o conflito. |
| Data/hora já passou | Escolha um horário futuro. |
| Fora do expediente (antes das 08h ou terminando depois das 20h) | Ajuste o horário ou escolha um serviço mais curto. |
| Domingo | Escolha outro dia. |

### Agenda do dia

Em **Agenda**, troque a data no campo de calendário para ver qualquer dia. Para cada atendimento em aberto:

- **Editar** — muda cliente, serviço, horário ou observação;
- **Concluir** — marca como realizado (entra no faturamento do dia);
- **Cancelar** — libera o horário para outro cliente.

Atendimentos concluídos ou cancelados ficam no histórico e não podem mais ser alterados.

## 6. Painel

Mostra os atendimentos de hoje, o total de clientes, os serviços ativos, o faturamento do dia (somente atendimentos concluídos) e os próximos 5 atendimentos.

## 7. Sair

Clique em **Sair** no menu.
