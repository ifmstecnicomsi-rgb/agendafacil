# Formulário de Teste (template)

Use este modelo para criar o formulário no **Google Forms** (ou Microsoft Forms). Cada colega preenche um.

| # | Pergunta | Tipo de resposta | Obrigatória |
|---|---|---|---|
| 1 | Nome completo | Resposta curta | Sim |
| 2 | Curso / área de atuação | Resposta curta | Não |
| 3 | Data do teste | Data | Sim |
| 4 | Em que dispositivo você testou? | Caixas de seleção: Computador, Celular, Tablet | Sim |
| 5 | Navegador usado | Múltipla escolha: Chrome, Edge, Firefox, Safari, Outro | Sim |
| 6 | **O que você testou e funcionou?** (descreva as funcionalidades) | Parágrafo | Sim |
| 7 | **O que você testou e NÃO funcionou? O que deve ser corrigido?** | Parágrafo | Sim |
| 8 | **Alguma funcionalidade ficou sem testar?** Por quê? (faltou, não encontrou, não estava implementada) | Parágrafo | Sim |
| 9 | Sugestões de melhoria | Parágrafo | Não |
| 10 | Prints das telas com erro | Upload de arquivo (imagem) | Não |
| 11 | De 1 a 5, quão fácil foi usar o sistema? | Escala linear 1–5 | Sim |
| 12 | De 1 a 5, qual a sua nota geral para o sistema? | Escala linear 1–5 | Sim |
